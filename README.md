## Stack Tecnológico

**Frontend:** Next.js 15 + React 19 + Tailwind CSS + Radix UI + TanStack Query/Table
**Backend:** NestJS + Prisma + PostgreSQL + Redis + BullMQ
**Shared:** Zod schemas + TypeScript types
**Infra:** Docker + AWS/Vercel + S3 + Meilisearch

---

## Contexto de referencia

Hotel de playa en Acapulco, 412 habitaciones, operación mixta:
- All inclusive + Plan europeo
- 5 restaurantes, 3 bares, boutique, spa
- Grupos turísticos, bodas, convenciones
- OTAs, agencias, corporativos, venta directa
- 4 salones de eventos
